# LumenFolio 小程序

微信小程序按 Android 配套 App 的使用顺序组织：先选择连接，再取景上传、查看相框图片或升级固件。取景、抖动和帧编码的算法顺序与 Windows、Android 共用的 panel 一致，小程序里是独立实现。

## 连接

- Wi-Fi：填写相框地址，探到相框后才进入。请求发到 `http://<地址>:8080`。
- 蓝牙：长按相框重刷键约两秒。小程序只发现正在广播相框服务的设备，不列出周围其他蓝牙。只有一台时直接连接，多台时再选择。第一次由系统弹出配对。
- 离线：可以取景和预览，不能上传或访问相框。

系统蓝牙设置占住连接后，相框不再广播。要再次连接时，先在系统里断开，不必遗忘配对，再长按重刷键。

## 取景、图库和固件

- 取景框为 3:4。六色预览用 120×160，上传按当前取景和所选算法生成完整的 1200×1600 EPD1 帧。
- 相框图片可查看 Flash 与 SD 卡容量、设备状态和缩略图，并显示或删除可选画面。开机画面保持受保护。蓝牙上这些请求按顺序发送。
- 固件可以从云存储下载，也可以从微信聊天文件选择。`cloudfunctions/firmware` 读取环境变量 `LUMENFOLIO_FIRMWARE_INDEX` 指向的 `firmware/index.json`。清单是数组，每项包含 `name`、`fileID`、`size` 和 `updated`。未配置时，固件页仍可使用手机里的文件。云开发不参与传图和图库。

## 易错点（务必遵守）

- **找不到相框** → 系统蓝牙还占着唯一连接，或 60 秒广播窗口已结束 → 在系统里断开该连接，长按重刷键约两秒后再查找。不要遗忘配对，否则下次要重新配对。
- **Android 找不到设备** → 搜索蓝牙需要定位权限 → 允许小程序使用定位后再试。
- **正式版里局域网地址被拒绝** → 微信普通请求要求备案域名，且明文端口不能落在 8000–8100，相框默认 8080 在此范围内 → 上架前改相框端口，或改走蓝牙。
