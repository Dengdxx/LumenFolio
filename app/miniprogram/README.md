# LumenFolio 小程序

微信小程序按 Android 配套 App 的使用顺序组织：先选择连接，再取景上传、查看相框图片或升级固件。取景、抖动和帧编码的算法顺序与 Windows、Android 共用的 panel 一致，小程序里是独立实现。

## 界面结构

- 底部四栏使用原生 `tabBar`（连接 / 取景 / 图库 / 固件），图标分未选中线稿与选中色块两套。原生底栏在页面 WebView 之外，`canvas type="2d"` 无法遮挡它；切换 Tab 也不再重建页面，取景页的已选照片与裁剪构图会保留。
- 连接方式做成底部半屏弹窗：点「Wi-Fi 连接」或「蓝牙连接」后弹出，点遮罩、关闭按钮或切换 Tab 关闭，蓝牙扫描同时停止。
- 浅色与暗黑模式跟随系统。`app.json` 开启 `darkmode` 并用 `theme.json` 的 `@` 变量驱动导航栏、窗口和 `tabBar` 配色，页面样式用 `prefers-color-scheme` 切换色块、线稿图标与品牌素材。
- 交互动效包括卡片与任务条的错峰入场、按压缩放、弹窗上滑、蓝牙扫描脉冲和缩略图淡入；全部使用纯 CSS，不引入额外脚本。

## 连接

- Wi-Fi：填写相框地址，探到相框后才进入。请求发到 `http://<地址>:8080`；输入框下方会实时显示补全后的目标地址，没写端口时自动补 `8080`。
- 蓝牙：长按相框重刷键约两秒。小程序只发现正在广播相框服务的设备，不列出周围其他蓝牙。只有一台时直接连接，多台时再选择。第一次由系统弹出配对。
- 离线：可以取景和预览，不能上传或访问相框。
- 未连接时打开「图库」或「固件」会显示引导卡，可一键回到连接页。

系统蓝牙设置占住连接后，相框不再广播。要再次连接时，先在系统里断开，不必遗忘配对，再长按重刷键。

## 取景、图库和固件

- 取景框为 3:4。上传按当前取景和所选算法在 1200×1600 上抖动并编码为 EPD1 帧；屏上预览改在半分辨率 600×800 上抖动，再按 2×2 块放大铺满 1200×1600 画布。预览显示宽度只有约 343 CSS px，单点仍小于一个 CSS 像素，看不出差别，而每帧少算四分之三的像素。
- 采样结果按 600×800 与 1200×1600 分槽缓存，抖动结果按「取景 + 算法」缓存：来回切「取景 / 六色预览」、重复进入预览页都直接复用上一次结果，只有换算法或改构图才重算。两个尺寸分开缓存，预览的半尺寸采样不会污染上传用的整幅采样。
- 取景画布放在带内边距的圆角相框里，`canvas` 的直角边不会压住外框描边；页面使用原生滚动，不再用 `scroll-view` 包裹画布。
- 相框图片可查看 Flash 与 SD 卡容量、设备状态和缩略图，并显示或删除可选画面。开机画面保持受保护。蓝牙上这些请求按顺序发送。
- 固件可以从云存储下载，也可以从微信聊天文件选择。`cloudfunctions/firmware` 读取环境变量 `LUMENFOLIO_FIRMWARE_INDEX` 指向的 `firmware/index.json`。清单是数组，每项包含 `name`、`fileID`、`size` 和 `updated`。未配置时，固件页仍可使用手机里的文件。云开发不参与传图和图库。

## 易错点（务必遵守）

- **找不到相框** → 系统蓝牙还占着唯一连接，或 60 秒广播窗口已结束 → 在系统里断开该连接，长按重刷键约两秒后再查找。不要遗忘配对，否则下次要重新配对。
- **Android 找不到设备** → 搜索蓝牙需要定位权限 → 允许小程序使用定位后再试。
- **正式版里局域网地址被拒绝** → 微信普通请求要求备案域名，且明文端口不能落在 8000–8100，相框默认 8080 在此范围内 → 上架前改相框端口，或改走蓝牙。
- **底部菜单被画布盖住** → 自定义 `<view>`/`<cover-view>` 底栏在部分模拟器里仍会被 `canvas type="2d"` 的原生层遮挡 → 保持四栏用原生 `tabBar`，不要改回页面内固定底栏。

## 预览

用微信开发者工具导入 `app/miniprogram`（含 `project.config.json` 的那一层）。切换深色预览：模拟器顶部工具栏的深浅色按钮；工具栏隐藏时按 `Ctrl + Shift + T` 调出，或用模拟器底部工具栏的「原生功能 / 模拟操作」菜单选择「深色 / 浅色」。
