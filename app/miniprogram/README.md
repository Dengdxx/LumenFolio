# LumenFolio 微信小程序

底部有 **连接**、**取景**、**图库**、**固件**四个入口。切换页面时，已选照片和取景构图会保留。

## 连接相框

| 入口 | 操作 |
| --- | --- |
| **蓝牙连接** | 长按相框重刷键约两秒，在白灯慢闪时打开蓝牙连接弹窗。只搜索正在广播相框服务的设备：只有一台时直接连接，多台时从列表选择。按系统提示配对，找不到时点 **重新查找**。 |
| **Wi-Fi 连接** | 按[局域网连接步骤](../../docs/quickstart.md#改用-wi-fi)取得相框 IP。在弹窗输入 `IP` 或 `IP:端口`，核对输入框下方显示的目标，再点 **连接相框**。省略端口时用 `8080`；手机和相框需处于同一网段。 |
| **离线取景** | 可取景和预览，不能传图、访问图库或升级。小程序不提供帧文件导出。 |

连接成功后进入 **取景**。在取景页点 **更换连接**会断开并返回 **连接**；仅切换底部标签不会断开。未连接时，**图库**和**固件**页提供 **前往连接相框**入口。

## 取景与传图

1. 在 **取景**页点 **打开图片**。在 3:4 取景框内拖动、双指缩放或旋转，也可点 **−90°**、**+90°** 或 **复位**。
2. 选抖动算法，切到 **六色预览**。小程序以 600×800 生成预览，上传时按当前构图和算法用完整的 1200×1600 分辨率编码为 EPD1 帧。
3. 选 **Flash** 或 **SD 卡**，点 **上传到相框**。检测到卡已挂载时默认选 SD 卡，另存一个帧文件；选 Flash 则覆盖上传槽，开机画面不变。
4. 等待最终状态文字，不要只看进度条。传输完请求体时进度就可能到 100%，此后还要等待写屏回执；旧固件没有该回执。收到写屏回执后，电子纸还要约 35 秒完成刷新。

## 查看相框图片

打开 **图库**，用 **Flash 空间**或 **SD 存储卡**切换来源。页面显示存储容量和设备上报的状态；**刷新**同时更新状态和当前列表。SD 卡有更多条目时，点 **继续加载更多画面**。

点条目后读取缩略图。点 **在相框上显示**可排队刷新，点 **删除**并确认可移除上传槽画面或 SD 文件。开机画面受保护。

## 固件升级

1. 连接相框，打开 **固件**。选择云端条目，或者把可信的 `LumenFolio.bin` 放到微信聊天文件里，再点 **从手机文件选择**。
2. 核对显示的版本，点 **开始升级**并确认。
3. 保持相框供电并停留在当前页面，等到小程序提示新固件已启动并确认。首次烧录或故障恢复见[固件部署](../../docs/firmware.md)，升级原理见[固件 OTA](../../docs/ota.md)。

## 开发准备

在微信开发者工具中导入 `app/miniprogram/`，使用有权限的 AppID。[`project.config.json`](project.config.json) 指定小程序根目录和基础库版本。可用模拟器工具栏的深浅色按钮，或模拟操作菜单切换主题。局域网请求使用明文 HTTP，须符合[微信的局域网通信规则](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/mDNS.html)。在手机上验证蓝牙配对、传图和 OTA，模拟器不能代替真实相框。

### 界面与预览实现

- [`app.json`](miniprogram/app.json) 使用原生 `tabBar` 保留标签页状态，避免页面内自定义底栏被 2D 画布遮挡。[`theme.json`](miniprogram/theme.json) 定义导航栏和底栏的深浅色样式，页面通过 `prefers-color-scheme` 切换品牌素材与色块，动效用 CSS 实现。
- Wi-Fi 和蓝牙连接使用半屏弹窗。关闭弹窗或离开连接页会停止蓝牙扫描。取景页用原生页面滚动，画布放在带内边距的相框里，避免压住外框描边。
- [取景页](miniprogram/pages/compose/index.js)将半分辨率预览按 2×2 像素块放大到 1200×1600 画布，抖动只处理整幅图四分之一的像素。两种分辨率分别缓存采样，预览结果按图片、构图和算法复用；上传不会使用预览的半分辨率采样。

### 配置云端固件列表（可选）

1. 为该 AppID 开通云开发，在当前环境部署 [`firmware` 云函数](cloudfunctions/firmware)，安装它声明的依赖。
2. 上传可用于 OTA 的 `LumenFolio.bin` 到云存储。创建并上传 UTF-8 的 `firmware/index.json`，内容为数组；每项填写 `name`（以 `.bin` 结尾）、`fileID`（固件的云文件 ID）、`size`（字节数）和 `updated`（更新时间）。
3. 在云函数环境变量中，将 `LUMENFOLIO_FIRMWARE_INDEX` 设为清单的云文件 ID，不是目录或文件名。打开固件页检查列表能否读取，点条目检查能否下载并显示版本。

未配置云开发时可从微信聊天文件选固件。云端不参与相框连接、传图或图库。

## 易错点（务必遵守）

- 搜不到相框 → 广播窗口已过期，或系统蓝牙已占住相框唯一的连接 → 先断开占用连接，不必遗忘配对；再长按重刷键并重新查找。
- Android 微信报定位相关错误 → 系统未允许微信扫描附近设备，部分版本还要求打开定位 → 按系统提示开启蓝牙、所需权限和定位，再查找。
- Wi-Fi 调试能用，关闭调试后连不上 → 调试环境可能跳过校验；真实设备仍受同网段和平台网络权限约束 → 在手机上核对 IP 与局域网权限，仍不通时走蓝牙。不要把明文服务暴露到公网来绕过限制。
- 图库能列出名称却加载不了预览 → 旧固件没有缩略图接口，小程序不会下载整帧补做预览 → 更新相框固件。
- 页面内固定底栏被画布挡住 → 部分环境的 2D 画布层会遮住自定义底栏 → 保留原生 `tabBar`，不要用页面内的 `<view>` 或 `<cover-view>` 替换。
