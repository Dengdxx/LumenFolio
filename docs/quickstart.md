# 第一次传图

用已烧录 LumenFolio 固件的相框和一张 PNG 或 JPEG，把照片传到相框并显示在屏幕上。空白主板先按[固件部署](firmware.md)烧录。

1. 准备支持蓝牙直连的应用和相框固件。Windows 安装程序和 Android APK 在 [GitHub Releases](https://github.com/Dengdxx/LumenFolio/releases) 的「配套 App」条目中。如果手上的安装包没有蓝牙入口，可以先[用 Wi-Fi 连接](#改用-wi-fi)，或从[当前源码构建应用](development.md)。使用微信开发者工具时，可按[小程序说明](../app/miniprogram/README.md)导入项目并在手机上预览。
2. 长按相框的重刷键（KEY3）约两秒，看到白灯慢闪后，在应用选 **蓝牙**（小程序在 **连接**页选 **蓝牙连接**）。只有一台相框在广播时应用会直接连接；有多台时选中目标。如系统弹出配对提示，确认配对。搜索不到时，重新长按重刷键，见[蓝牙连接](bluetooth.md)。
3. 点 **打开图片**，在 3:4 取景框内平移、缩放或旋转照片，再点 **六色预览**。第一次可以保留应用默认的抖动算法。
4. Flash 只保留一张上传画面，新图会覆盖上一张，但不影响开机画面。如果要保留多张，插好 SD 卡并选择 **SD 卡**；否则选 **Flash**（Android 上是 **Flash artifacts**）。点 **上传到相框**。
5. 等待应用提示已写屏。像素和刷新命令送到面板后，画面还要约 35 秒才稳定。用小程序时以最终状态文字为准，进度条的 100% 可能只代表传输结束。

## 改用 Wi-Fi

相框使用 2.4 GHz Wi-Fi，默认连接热点 `smd`，密码为 `88888888`。用可信的局域网；相框的 HTTP 服务没有登录验证或 TLS，不要把它暴露到公网。

1. 开启热点，让运行应用的电脑或手机也接入同一网络。短按相框机身键唤醒，等待它连上热点。
2. 在热点的已连接设备列表中找 `LumenFolio` 的 IP，也可以从 USB 串口日志的 `wifi: 已连上 ...` 一行读取。重新接入热点后地址可能变动。
3. 在应用选 **Wi-Fi**，填入相框 IP，再点 **连接**。小程序在 **连接**页选 **Wi-Fi 连接**，填写后点 **连接相框**。默认端口为 `8080`。

## 易错点（务必遵守）

- 相框原来的画面还在，却连不上 → 电子纸在深睡时仍保留画面，Wi-Fi 和蓝牙已关闭 → 短按唤醒；要用蓝牙则长按重刷键。详细规则见[低功耗与深睡](低功耗.md)。
- 相框找不到热点 → 相框只支持 2.4 GHz，且默认连接特定热点名 → 核对 `smd` 的名称、密码和频段。
- 小程序里访问局域网失败 → 微信的局域网请求要求手机与相框在同一网段，系统也可能限制访问 → 核对网络及微信的局域网权限，仍连不上时用蓝牙。
