# Windows 应用

从 [GitHub Releases](https://github.com/Dengdxx/LumenFolio/releases) 下载并安装配套 App 的 Windows x64 安装程序。图形界面和命令行共用 `LumenFolio.exe`。要构建与当前源码一致的版本，见[构建 Windows 应用](development.md#构建-windows-应用)。

## 连接相框

打开应用先选 **Wi-Fi**、**蓝牙**或**离线**。连接步骤见[第一次传图](quickstart.md)。离线可以取景、预览和导出。点 **更换连接**会断开并返回连接页，记住的 Wi-Fi 地址不会自动重连。

## 窗口和主题

需要 Windows 上的微软雅黑（`C:\Windows\Fonts\msyh.ttc`）。找不到时仍能打开，但中文会变成方框。

界面启动时读取 Windows 的应用颜色设置。浅色主题采用暖白和陶土色，深色主题采用炭黑和蓝色，取景、图库和固件升级与 Android 版使用相近的配色。

窗口控制按钮位于界面右上角；在取景页拖动左上角品牌区域、图库页拖动标题区域、升级页拖动左上角空白区域可移动窗口。双击这些区域可最大化或还原，拖动窗口边缘可调整大小。

图形界面和命令行共用 `LumenFolio.exe`。Windows 11 24H2（内部版本 26100）及更新版本支持清单里的无参不分配终端设置，双击时直接打开界面。从已有终端带子命令运行时，输出和退出码仍由终端接收。

## 取景

点击 **打开图片**选择 PNG 或 JPEG；也可以将图片路径作为 EXE 的唯一参数。取景框固定为 3:4，拖动时移动的是框后的原图：

- 鼠标左键拖拽：平移
- 滚轮：以指针位置为锚点缩放
- 右键拖拽，或拖动框顶的把手：围绕框中心旋转；按住后移出画布仍可继续拖动
- 侧栏的 `-90°`、`+90°` 和「复位」：整数旋转或恢复初始构图
- 顶部**取景选取**、**六色预览**标签：切换视图

框外压暗。原图盖不住的地方填白，透明 PNG 也按白底合成。

## 抖动

切到「六色预览」后，程序先按取景框把原图采样成 1200×1600，再做抖动并等比缩小显示完整构图。抖动不在缩小后的预览图上做，否则颗粒和上屏不一致。

在侧栏选择[抖动预设](dither.md#预设)，列表超出侧栏时可以滚动。墨水是黑、白、黄、红、蓝、绿，索引与固件帧缓冲的半字节一致。Bayer、随机噪声和蓝噪声在输入像素精确命中墨水时保持该墨水。界面上的颜色只是这些墨水的 RGB 近似，不是面板的真实反射。

拖拽或滚轮停下来约 120 ms 后重新采样并抖动。旧版本任务的结果不会覆盖当前取景与算法的预览。

## 传到相框与导出

相框连上后，已挂载 SD 卡时默认选 **SD 卡**，否则选 **Flash**。也可以手动选目标；换卡后点 **检测**重新读取容量。

**上传到相框**按当前取景与算法编码。压缩后更小时用 EPD2，否则用 EPD1。选择 SD 卡会新增独立帧文件，选择 Flash 会覆盖 artifacts 上传槽。开机画面保留。

底部状态区显示无线传输、保存和 SPI 写屏进度。收到 SPI 完成回执时进度到 100%，屏幕刷新约需 35 秒。旧固件可接收 Flash 上传，界面提示回执可用情况。

「导出帧文件」用同样的编码写到本地 `.bin`，无需连接设备。

## 查看相框图片

用 Wi-Fi 或蓝牙连接相框，点击「查看相框图片」。顶部显示两种来源各自的已用容量、总容量和占用比例，以及设备上报的电量、充电状态、温度和湿度。可在「Flash artifacts」和「SD 卡」间切换。Flash 列出已有帧的开机槽和上传槽。支持分页的固件按文件名列出 SD 卡根目录的 `.bin` 帧文件，滚动接近列表末尾时自动追加下一页。

缩略图优先逐张加载可见条目，再预取下方两项。旧固件不支持缩略图接口时，应用下载整帧生成小图。点击列表项可查看完整六色预览。预览下方的「在相框上显示」会让支持该功能的固件从原存储位置读图并安排显示，屏幕刷新约需 35 秒。

选择 SD 卡图片或 Flash 上传槽的画面后，点击「删除图片」，核对名称和来源，再点「确认删除」。Flash 开机画面受保护。删除成功后，应用清除当前预览并重新读取列表和容量。

点击「刷新状态」重读容量和设备状态，保留当前图片和缩略图。点击「刷新列表」从当前来源的第一页重读画面。设备提供图片版本时，匹配版本的小图可以复用。点击「返回」继续本地取景。

## 固件升级

用 Wi-Fi 或蓝牙连接相框，点击侧栏的「固件升级」并选择已下载的 `LumenFolio.bin`。核对文件名与版本后点击「确认升级」，等待应用显示新固件已启动并确认。连接与恢复见[固件 OTA](ota.md)。

## 命令行

命令行按整图等比放进面板、居中、不旋转来编码，`frame` 子命令通过 Wi-Fi 上传到 Flash。它优先用送屏进度接口，旧固件回退到 `POST /frame`。用 `ota` 子命令升级固件，见[命令行升级](ota.md#通过命令行升级)。未知命令的退出码为 2。

```powershell
.\app\pc\LumenFolio.exe export 照片.png 画面.bin
.\app\pc\LumenFolio.exe --host 192.168.137.42 frame 照片.png
```

`--alg` 是[抖动预设序号](dither.md#预设)，默认 `1`（同向扫描的 Floyd-Steinberg）。导出的文件可放入 SD 卡根目录，用机身按键翻页显示。

## 帧格式与兼容性

参见 [EPD1 与 EPD2 帧格式](frames.md)。

## 易错点（务必遵守）

- 双击时弹出终端 → 当前 Windows 可能不支持清单的终端分配设置 → 核对系统是否为 Windows 11 24H2（内部版本 26100）或更新版本，并使用本项目构建的 EXE。
- 中文显示成方框 → 无法加载 `C:\Windows\Fonts\msyh.ttc` → 确认 Windows 已安装微软雅黑。
- 上传回执到了，画面还没切换 → 旧接口的 202 不保证写屏，新接口的 100% 也只表示已发送刷新命令 → 等画面稳定；仍无变化时看串口显示任务日志并重新导出或上传。
- 旧固件拒绝传图或无法浏览 → 固件不支持压缩帧或读图接口 → 按[固件 OTA](ota.md)升级相框后重试。
