# 指示灯

相框的 WS2812 指示灯用于显示蓝牙、刷屏和电池状态。一次性提示播完后，灯恢复显示当前仍有效的持续状态。

## 持续状态

多个状态同时存在时，从表中自上而下选择优先级最高的一项。都不满足时熄灯。

| 灯光 | 含义 |
| --- | --- |
| 黄色慢闪 | 显示任务正在向电子纸送图或等待本轮刷新结束 |
| 蓝色快闪 | 蓝牙正在桥接一条相框请求，包括传图、图库或升级 |
| 白色慢闪 | 相框正在广播，等待蓝牙连接；连上后停止广播 |
| 电量色常亮 | 检测到正在充电或已充满。颜色随电量从红过渡到绿 |

## 一次性提示

| 灯光 | 含义 |
| --- | --- |
| 红色快闪十次 | 面板初始化、图像载入或刷屏失败。用串口日志和[控制台的 `status`](控制接口.md#控制台)定位 |
| 电量色亮约 1.2 秒 | 本次启动后第一次成功采样；接入充电器或插电时电量比上次提示变化至少 5 个百分点也会重播 |
| 蓝色亮约 0.6 秒 | 蓝牙连接启用加密 |
| 绿色亮约 0.6 秒 | 刷屏完成，包括无帧缓冲时的六色条纹降级路径 |
| 黄色短闪约 0.12 秒 | 按上一张或下一张时，SD 卡上没有可用帧 |

快闪的亮、灭各约 150 ms，慢闪各约 600 ms。亮度和时序以 [`led_fsm.cpp`](../main/led_fsm.cpp) 的当前参数为准，未作实机标定。

## 实现边界

[`led_fsm`](../main/led_fsm.h) 独占 WS2812 的 RMT 通道。显示、采样和蓝牙任务只投递事件或设置持续状态，不直接写灯。事件不打断正在播放的灯效；投递队列满时可能丢事件，因此灯光不是逐条命令的回执。当前 Wi-Fi 连接、Wi-Fi 传图和挂载 SD 卡未接入灯语。

## 易错点（务必遵守）

- 白灯不闪却搜不到相框 → 相框已经连到其他应用，或广播窗口已结束 → 先断开占用连接，然后[重新打开蓝牙窗口](bluetooth.md)。
- 插线后灯没常亮 → 充电状态尚未被成功采样，或相框仍在深睡 → 按机身键唤醒，再用 `status` 核对充电状态。直接插线不会唤醒相框。
- 深睡前灯还亮着 → WS2812 接在常电电源轨上，停止 RMT 不会清掉灯色 → 先调用 `led_fsm_suspend()` 写黑色再入睡；不要在挂起后直接驱动灯。写黑色只能熄灯，不能消除静态电流。
