# 蓝牙连接

Windows 和 Android 配套 App 可以通过低功耗蓝牙直接连接 LumenFolio。连接后可以上传到 Flash 或 SD 卡，查看状态、容量和图库，预览、显示或删除图片，以及上传并确认固件升级。相框和 App 无需接入同一个 Wi-Fi，传图仍有上传、保存和 SPI 写屏回执。

## 连接相框

1. 相框使用支持蓝牙连接的固件。首次升级可以通过 [局域网 OTA 或 USB](ota.md) 完成。
2. 长按相框的 KEY3（重刷键）约两秒，白灯慢闪时可在 60 秒内发现相框。深睡时也可以直接按住 KEY3 唤醒并进入连接窗口。
3. 打开 App 先停在连接页，选「蓝牙」。打开系统蓝牙并授权扫描。只有一台 LumenFolio 在广播时直接连接，多台时再选择。系统提示配对时确认。
4. 连接成功后进入工作区，可以传图、查看相框图片或升级固件。App 读取相框的 `id`，并按蓝牙地址减 2 核对是不是同一台。点「更换连接」会断开并回到连接页，已填过的 Wi-Fi 地址保留，但不会自动重连。

相框一次只接收一个蓝牙连接。连接窗口到期后，已连接的 App 可以继续操作。切换连接设备时，先断开当前连接，再长按 KEY3。

## 固件升级

在蓝牙已连接时打开「固件升级」，选本地的 `LumenFolio.bin`，等 App 显示新镜像启动并确认。上传和重启期间保持 App 打开、相框供电，待确认的镜像会短暂恢复广播，让原 App 自动重连。

## 传输边界

固件的 NimBLE GATT 服务要求加密，系统用 Just Works 配对。相框接收蓝牙请求后，通过本机回环复用现有 HTTP 路由。Wi-Fi 和蓝牙使用同一套帧校验、文件操作、SPI 队列和 OTA 回滚逻辑。

两端 App 和命令行共用一次相框会话：传图、图库和固件升级都从当前会话发起，页面不再各自保存地址。蓝牙链路按顺序收发请求，断线后下个请求可重连，已发出的写请求不会自动重发。同一时间只保留一条会话，切换连接会先关闭旧会话。

## 易错点（务必遵守）

- **搜不到相框** → 深睡会关闭射频，或 60 秒窗口已结束 → 长按 KEY3 约两秒，重新搜索。
- **提示连上了另一台相框** → 这次的 `id` 和 App 记住的不同 → 确认是不是换了设备。旧固件不报 `id`，App 不会拦截。
- **从已有构建目录编译时报 NimBLE 不可用** → 生成的 `sdkconfig` 仍关闭蓝牙 → 执行 `idf.py --preset release fullclean`，再用 Release preset 构建。Debug 使用对应的 `debug` preset。
- **Android 提示无法扫描** → Android 12 及以后需要「附近的设备」权限，Android 8–11 扫描需要位置权限和系统定位开关 → 在系统设置中打开对应权限后重试。
- **蓝牙传整帧或固件较慢** → 速度取决于双方协商的 ATT MTU 和连接间隔 → 保持在相框附近，等待 App 的传输进度。链路中断后，核对图库或 OTA 状态再决定是否重试。
